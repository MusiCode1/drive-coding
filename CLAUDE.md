# CLAUDE.md

This project uses **`AGENTS.md`** as the canonical guide for working here — read it first.

**Long-term planning** lives in **`docs/roadmap.md`** (the master roadmap: vision, work
tracks, milestones). Any planning that is not an immediate task must be checked against it
and recorded there (or in a sub-roadmap it links to) — don't let long-term plans live only
in conversation.
