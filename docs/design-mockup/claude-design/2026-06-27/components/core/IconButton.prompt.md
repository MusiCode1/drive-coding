`IconButton` is a round, icon-only control used throughout DriveCoding for secondary actions.

```jsx
<IconButton icon="copy" size="xs" ariaLabel="העתק" />
<IconButton icon="square" size="lg" variant="muted" ariaLabel="עצור" />
<IconButton icon="folder" variant="soft" ariaLabel="בחר תיקייה" />
```

Sizes: `xs`(22, bubble chip) / `sm`(32) / `md`(44, tap minimum) / `lg`(56, drive-first side control). Variants: `soft | solid | ghost | muted`. Always set `ariaLabel`.
