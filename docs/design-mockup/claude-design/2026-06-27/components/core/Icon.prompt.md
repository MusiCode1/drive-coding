`Icon` renders a Lucide outline icon from DriveCoding's curated set at the product-standard 1.75 stroke, inheriting `currentColor`.

```jsx
<Icon name="mic" size={20} />
<Icon name="sparkles" size={15} style={{ color: "var(--accent-hi)" }} />
```

Names: mic, mic-off, volume-2, square, loader, x, send, user, sparkles, brain, wrench, copy, check, play, folder, keyboard, eye-off, chevron-down, settings, plus, trash-2, refresh-cw, car. Use `ICON_NAMES` for the full list. Strokes inherit text color; set `color` on the parent or via `style`.
