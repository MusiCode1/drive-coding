`Avatar` is the small round identity chip beside each chat bubble — a Lucide icon on a soft tint, keyed by role.

```jsx
<Avatar kind="agent" />
<Avatar kind="user" />
<Avatar kind="thought" />
<Avatar kind="tool" size={24} />
```

`kind`: user (user icon) / agent (sparkles) / thought (brain, on thinking tint) / tool (wrench). Default size 28px.
